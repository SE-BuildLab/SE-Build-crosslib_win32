Summary / 概要: The Marvin Attack (Hubert Kario, Red Hat) is a timing side-channel variant of the Bleichenbacher padding oracle attack against RSA PKCS#1 v1.5 decryption: an attacker who can measure the response time of a server decrypting attacker chosen ciphertexts can decrypt previously captured ciphertexts or forge signatures. For the OpenSSL API the oracle is the result itself - RSA_private_decrypt()/EVP_PKEY_decrypt() return an error (and a different output length) when the padding is invalid, and applications cannot handle this in a side-channel free way. The mitigation ('implicit rejection', as in OpenSSL 3.2) returns a deterministic pseudo random message derived from the private key and the ciphertext instead of an error, so that invalid padding is indistinguishable from a genuine random plaintext. / Marvin 攻撃 (Hubert Kario 氏、Red Hat) は RSA PKCS#1 v1.5 復号に対する Bleichenbacher パディングオラクル攻撃のタイミング変種で、攻撃者が選んだ暗号文を復号するサーバの応答時間を計測できれば、捕捉済み暗号文の復号や署名の偽造が可能になる。OpenSSL の API ではオラクルは結果そのもの、すなわちパディング不正時に RSA_private_decrypt()/EVP_PKEY_decrypt() がエラー (と異なる出力長) を返すことであり、アプリケーション側でサイドチャネル無しに扱うことはできない。対策 ('implicit rejection'、OpenSSL 3.2 と同じ) はエラーの代わりに秘密鍵と暗号文から決定的に導出した疑似乱数メッセージを返し、不正パディングを本物の乱数平文と区別不能にする。
